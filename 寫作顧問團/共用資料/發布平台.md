# 發布平台規範

## KC AI 教育手記發布版型

- 參考版型：使用者提供的〈我們其實都知道怎麼學，只是從來沒有用它來檢視學習〉HTML。
- 閱讀寬度：最大約 600px。
- 主色：赤陶色 `#C0512F`；背景使用暖米色。
- 字體：使用參考頁面的宋體／思源宋體風格；順序為 `Georgia`、`Noto Serif SC`、`Noto Serif TC`、`Songti SC`，並以新細明體作繁體中文備援。
- 主標題之前只保留固定品牌開頭與細分隔線；不得出現工作台名稱、來源檔名、修改摘要、編輯按鈕或操作說明。
- 二級標題使用赤陶色文字及左側直線。
- 關鍵轉折可使用實色赤陶色框；核心論點可使用淡色底與左側線；方法列表使用一致但克制的單元樣式。
- 正式上傳檔以行內樣式為主，降低平台清除外部 CSS 的風險。
- 乾淨發布檔的檔名必須與文章專案資料夾完全相同，例如資料夾為 `2026-08-07-把學習時間還給孩子`，輸出即為 `2026-08-07-把學習時間還給孩子.html`。
- `文章工作台.html` 保留為可編輯草稿工作區。
