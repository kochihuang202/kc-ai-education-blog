## 2026-08-07｜建立固定文章工作台

- 使用者目標：需要一個舒適的單一閱讀／編輯畫面，既能自己修改，也能交由寫作 Agent 修改。
- 固定入口：新增 `文章工作台.html`，後續永遠同步最新 Markdown 稿件。
- 閱讀功能：乾淨排版、調整字級、淺色／深色模式。
- 編輯功能：開始／完成編輯、復原、重做、瀏覽器暫存、放棄修改與匯出 Markdown 修改稿。
- 協作方式：使用者自行修改後匯出，寫作 Agent 匯入為新版本；寫作 Agent 修改後自動重建工作台。
- 限制：基於瀏覽器安全，使用者修改後需按一次「儲存修改稿」，網頁不能無提示地覆寫正式稿件。
